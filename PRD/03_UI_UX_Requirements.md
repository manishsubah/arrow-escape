# UI/UX Requirements

The game's design is based on a playful style with a light theme and a color palette consisting of #3B82F6 (Primary), #64748B (Secondary), #06B6D4 (Accent), #0F172A (Background), #1E293B (Surface), and #F8FAFC (Text). The game features Poppins as the primary font.

Responsive breakpoints are set at 375px, 750px, and 1024px.

The core screens are as follows:

- Splash Screen: Shows the game logo.
- Home Screen: Displays the game title, level selection, and settings options.
- Level Selection Screen: Allows users to select a level to play.
- Game Screen: Shows the puzzle board and allows users to tap arrows to remove them.
- Level Complete Screen: Displays a congratulatory message and offers to unlock new levels.
