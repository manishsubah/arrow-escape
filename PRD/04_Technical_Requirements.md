# Technical Requirements

The game will be built using Flutter, a cross-platform mobile development framework. The backend is not required, as the game is offline. The game will store 100 pre-defined levels locally and no authentication is needed.

The game's folder structure will be as follows:

```
arrow-escape/
|-- assets/
|   |-- images/
|   |-- sounds/
|   |-- fonts/
|-- lib/
|   |-- main.dart
|-- pubspec.yaml
```

Key API endpoints or data flow are not required, as the game is offline. The basic data schema for the game will be stored locally on the device.

GLOBAL RULES:

1. Emojis are not allowed in the output.
2. Custom technologies, colors, or fonts that the user did not choose should not be used.
3. Only real, currently popular, well-maintained libraries/packages relevant to the chosen stack should be recommended.
4. The output should match the depth and complexity of the user's description and guiding notes.
5. Use clean, professional Markdown with headers, tables, and bullet lists.
6. The tone should be concise, professional, and developer-facing.
7. Every requirement should trace back to something the user actually asked for.
